SYSTEM — แพ็กเกจติดตั้งเป็นแอปบนมือถือ (PWA)

วิธีติดตั้งบน Android
1. แตกไฟล์ ZIP นี้
2. นำไฟล์และโฟลเดอร์ทั้งหมดใน SYSTEM_PWA ไปวางบนโฮสติ้งที่รองรับ HTTPS (เช่น GitHub Pages, Netlify หรือ Vercel)
3. เปิด URL ของเว็บที่อัปโหลดด้วย Chrome บนมือถือ
4. เลือกเมนู ⋮ > ติดตั้งแอป (Install app) หรือ เพิ่มลงในหน้าจอหลัก
5. เปิดแอปจากไอคอน SYSTEM บนหน้าจอมือถือ

หมายเหตุ
- แพ็กเกจนี้เป็น PWA ไม่ใช่ไฟล์ APK โดยตรง การติดตั้งต้องเปิดผ่านเว็บไซต์ที่ให้บริการ HTTPS
- Service Worker ช่วยแคชหน้าแอปเพื่อให้เปิดใช้งานออฟไลน์ได้หลังจากเปิดออนไลน์ครั้งแรก
- ข้อมูลความคืบหน้าเดิมของ HTML ใช้ localStorage จึงผูกกับ origin/เบราว์เซอร์ที่ใช้งาน ไม่ได้ย้ายข้ามโดเมนหรือจากไฟล์เดิมให้อัตโนมัติ
- Google Fonts ต้องเชื่อมต่ออินเทอร์เน็ตในครั้งแรก; หากโหลดไม่ได้ ระบบจะใช้ฟอนต์สำรอง
